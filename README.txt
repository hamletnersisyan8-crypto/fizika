# Կայքի գործարկում

1. Տեղադրեք Node.js-ը։
2. Տերմինալում այս թղթապանակում կատարեք՝ `npm install`
3. `.env.example` ֆայլը պատճենեք և վերանվանեք `.env`։
4. `.env`-ում լրացրեք ձեր Gmail հասցեն, նոր Google App Password-ը և ստացող հասցեն։
5. Գործարկեք՝ `npm start`
6. Բացեք՝ http://localhost:5000

Կարևոր.
- Մի հրապարակեք `.env` ֆայլը և մի տեղադրեք այն GitHub-ում։
- Քանի որ նախորդ հաղորդագրության մեջ App Password էր հայտնվել, չեղարկեք հինը և ստեղծեք նորը։
- IP հասցեի հավաքման/օգտագործման մասին այցելուներին տեղեկացրեք կայքի գաղտնիության ծանուցմամբ։
- TRUST_PROXY=true միացրեք միայն վստահելի proxy-ի հետևում տեղակայելիս։
- Այցելության ծանուցումը աշխատում է գլխավոր էջի `/` այցելությունների համար։
